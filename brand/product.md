# Lume — product design brief

For CAD, CMF, and the first physical crate. Brand book: [Lume Brand Book](https://www.figma.com/design/nHVRXhCWmjrwd9MTGiGSYF) · page **08 Object**.

The object is outdoor furniture that moves air. Not a gadget. Not a rangehood. Not a grill.

## Squint test

Stand the prototype next to a Vipp bin and a By Lassen Kubus.

- If it belongs in that room, freeze the silhouette.
- If it still looks like a fan, a shop vac, or a BBQ accessory, the object is the problem — not the website.

Santa & Cole is the Spanish check: a technical thing that can live in a civil interior. Balmuda is the ritual check: it must earn Sunday, not wattage.

## Job

Capture smoke at the grate of a balcony parrilla, including charcoal. No ducts. No drill into common structure. Quiet enough to talk. The neighbour’s window can stay open.

If it only works on induction, it is not Lume.

## Form

- One silhouette. Read as a single mass, not an assembly of vents.
- Aim at the grate. The geometry should make the capture plane obvious without a diagram.
- Mount: clamp, stand, or hang. Never a hole in the façade, railing weld, or common slab.
- Radius **8 mm** on the object (`radius.object`). Not sharp sheet-metal, not appliance blob.
- Human height, next to a real parrilla. Scale against a railing, a plant, a mop — not a 4K outdoor kitchen.
- It stays out, like a lamp. Do not design a thing that wants to be hidden in a cabinet.

Leave: exploded CGI language, visible cyclone theatre, knurling as personality, LED rings, fake wood, piano black, mirror stainless.

## CMF

Lock paint chips in sun, grease, and night before tooling. Until then, this is the target.

| Role | Spec | Use |
|---|---|---|
| Body | Powder-coated **charcoal** `#1C1917` | Near-black metal, warm, not cool grey. The ground. |
| Ember | `#C45C26` | One coal per object: a single control accent. Never a flood, never a stripe kit. |
| Ember pressed | `#9A3F16` | Optional on a pressed mark. |
| Sand | Optional later | Second colourway only after charcoal is true. |
| Signal OK | `#3F6B4E` | Filter OK. Hardware or a small window, never decoration. |
| Signal alert | `#A33B2B` | Replace filter / safety. Never brand decoration. |

Finish: matte to satin powder. Grease is honest. Fingerprints should not become the texture.

Not: brushed aluminium gadget, chrome, copper theatre, camouflage, flag colours, Buster + Punch hardware.

## Controls

Braun, not Dyson. The object teaches. No app to start the fan.

- One knob, **or** three physical speeds + off.
- Delay-off (so they can leave the grate without standing there).
- Optional warm light — a lamp, not a gaming ring.
- No greasy capacitive sliders.
- No screen. No Wi-Fi required. A plug, not a platform.

The ember on the object is that one control. Everything else stays charcoal.

## Graphics on the object

- Wordmark: **Lume**, IBM Plex Sans Regular, open tracking. No flame icon. The object is already fire.
- On charcoal: wordmark in field `#F4F0EA`.
- Clear space: the height of the **L** on all sides.
- Never: script, extra-bold, a drawn flame, a little house, letterspacing so tight it reads as Lurne.
- Pictograms for Encender / Apagar / Limpiar. Infinitive only. No vos, no tú on the object.

## Service (this is form)

If service is ugly, the object is unfinished.

- Grease tray and filters: sink, no tools.
- Cooks-per-filter printed honestly on the pack — not fairy-tale months.
- Spare parts for seven years.
- Filter OK / replace uses signal colours only, and only there.

## Pack (the second product)

Fits a small elevator. One adult. No crate. Kraft or field board, charcoal type, one ember rule. Spare filter visible as a kindness.

## Claims the hardware must make true

Engineering owns the first column. Do not style a lie.

- Captures at the grate, on charcoal.
- No ducts. No drilling into the building.
- Reduces plume and odour leaving the balcony. Does not eliminate smoke.
- Quiet enough to talk. State dB calmly when measured.
- Does not legalise fire where the reglamento forbids it.

## Stay away (aisles that break the object)

Weber, Traeger, Big Green Egg, Ooni. Dyson. Gaggenau / Wolf / outdoor-kitchen CGI. Smeg. Buster + Punch. Nest and smart hoods.

## Freeze

When the prototype passes the squint test, lock CMF and silhouette. Do not keep collecting references.
